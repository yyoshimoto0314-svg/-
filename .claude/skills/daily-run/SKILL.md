# デイリー実行（部門連携）

引数：テーマ（省略時はおまかせ）。

1. `/note-pipeline` の手順で note 記事を1本作る（QA PASS まで）。
2. 同じ記事ディレクトリを入力に、`/video-pipeline` のパターンBでショート動画を作る。
3. `output/<日付>/report.md` に日報を書く：
   ```
   # 日報 <日付>
   ## 成果物
   - note記事: <タイトル>（<文字数>字）→ article.md
   - ショート動画: <秒数>秒 → video/short.mp4, thumbnail.png
   ## QA
   - 記事: PASS/FIX… / 動画: …
   ## 人間にお願いしたいこと
   - note の下書きを確認して公開
   - 動画を確認して投稿
   ```
4. Git 管理下で実行している場合、`output/` は Git に入れない。成果物の共有は Google Drive などで行う。
5. 最後に日報の要約を3行で返す（定期実行の通知に使われる）。
