# AIエージェント組織 構築ロードマップ

Claude（Claude Code / Cowork）の中に「AIエージェントの会社」を作り、
**note記事の自動作成** と **動画の自動編集** を部門として組み込み、サービスとして展開するまでの手順。

前提：前回作った AI自動化サービス = `note-article` スキル（「今日のnote」で起動）
- アカウント「越境インプット」：海外の一次情報を、日本語で、実験して届ける
- 海外YouTube 3〜5本のリサーチ → 型A/B/C で執筆 → セルフチェック → Chrome で note に下書き保存
- 体験談は本人が書く／1日1本／公開は人間が押す
これを「note記事部門」の中核としてそのまま活かし、周りを組織として固める。

---

## 全体像

```
                        ┌──────────────────────────┐
                        │  CEO（統括エージェント）   │  ← メインのClaudeセッション
                        │  CLAUDE.md = 組織憲章     │     依頼を受けて各部門に割り振る
                        └────────────┬─────────────┘
              ┌──────────────────────┼──────────────────────┐
     ┌────────▼────────┐    ┌────────▼────────┐    ┌────────▼────────┐
     │  note記事部門     │    │  動画編集部門     │    │  品質管理（QA）   │
     │ researcher       │    │ scriptwriter     │    │ qa-reviewer      │
     │ writer           │──▶│ editor(ffmpeg)   │    │ 事実・炎上・権利   │
     │ editor（校正）    │記事│                  │    │ チェック          │
     └──────────────────┘→台本└──────────────────┘    └──────────────────┘
```

ワンソース・マルチユース：1本のリサーチから「note記事」「動画台本」「ショート動画」を作る。

## 各ステップの詳細

### Step 1. 組織の土台づくり
- `CLAUDE.md`：CEO（メインセッション）の行動規範。依頼を部門に振り分けるルール、品質基準、禁止事項。
- `config/brand.yaml`：誰に・何を・どんな口調で届けるか（ペルソナ、トーン、NGワード）。
  顧客ごとにこのファイルを差し替えれば、同じ組織を別ブランドで動かせる（Step 7 の布石）。
- `.claude/agents/*.md`：部門メンバー（サブエージェント）の定義。

### Step 2. note記事部門
- 既存スキル `note-article` を「リサーチ担当」「執筆担当」「校正担当」に分解し、
  間に QA を挟むことで品質を安定させる。
- 成果物：`output/YYYY-MM-DD/<slug>/article.md`（＋ `sources.md`）。
- 実行：`/note-pipeline <テーマ or おまかせ>`

### Step 3. 動画編集部門
- `video/autoedit.py`（ffmpeg ベース、追加ライブラリ不要）
  - `cut-silence`：無音・間延びを自動カット（ジェットカット）
  - `subtitles`：SRT 字幕の焼き込み（日本語フォント対応）
  - `bgm`：BGM 合成（話し声で自動的に BGM を下げるダッキング）
  - `vertical`：横動画 → 9:16 縦型（ショート/リール/TikTok 用）
  - `thumbnail`：サムネイル生成（タイトル文字入れ）
  - `run`：上記を JSON ジョブ1本でまとめて実行
- 文字起こし（自動字幕）は `faster-whisper` を入れると自動化される（任意）。
- 実行：`/video-pipeline <素材動画 or ジョブファイル>`

### Step 4. 部門間連携（`/daily-run`）
1. note部門がテーマ選定＆記事作成
2. 動画部門の台本担当が記事から「60秒ショート台本」「字幕SRT」「サムネ文言」を作る
3. 素材動画があれば自動編集、なければ台本のみ納品
4. QA が全成果物をチェックして `output/YYYY-MM-DD/report.md` にまとめる

### Step 5. 定期実行
- Claude Code の Routines（スケジュールトリガー）で `/daily-run` を毎朝起動。
- 完了時にプッシュ通知 or メール。成果物は Git / Google Drive に保存。

### Step 6. 公開・配信の接続
- note：公式APIがないため「下書き保存まで自動、公開ボタンは人間」が安全。
  Claude in Chrome / ブラウザ操作で下書き投稿。
- 動画：YouTube Data API / 各SNSの予約投稿機能、または Drive 納品で人が投稿。

### Step 7. サービス化
- 顧客ごとに `clients/<顧客名>/brand.yaml` を作り、同じ組織で複数ブランドを運用。
- メニュー例：note記事代行（月◯本）、ショート動画自動編集（月◯本）、両方セット。
- 士業事務所向け（集客記事＋解説ショート）などの業種パッケージ化。

### Step 8. 運用・改善
- `metrics/` に記事・動画ごとの成果を記録 → CEO がテーマ選定に反映。

## ディレクトリ構成

```
CLAUDE.md                  組織憲章（CEO の行動規範）
config/brand.yaml          ブランド・ペルソナ設定
.claude/agents/            部門メンバー（サブエージェント）
.claude/skills/            部門の業務フロー（/note-pipeline, /video-pipeline, /daily-run）
video/autoedit.py          動画自動編集エンジン
video/jobs/                動画編集ジョブ（JSON）
docs/                      手順書・部門マニュアル
output/                    成果物（Git管理外）
```
