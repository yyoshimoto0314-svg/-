# 問い

note 記事（AI支援で1日1本）で、個人がどれくらい・どれくらいの期間で収益化できるか
（対象：note アカウント「越境インプット」＝海外YouTubeを日本語で紹介する男性向けビジネス・自己啓発 note。`config/brand.yaml` 準拠）

調査日：2026-10-02（JST）／調査担当：marketing-researcher

---

## 結論（3行）

1. note は伸びている市場（会員1,248万人・四半期GMV 64.8億円・YoY+24.6%）だが、売上は上位に極端に集中する。上位1,000人で年間流通総額の約7割を占める（推計）。普通の個人が最初の1年で目指せる現実的な水準は「月0〜数千円」で、「月1万円」に届くのは少数派。
2. 実践者の公開例では、初収益まで3週間〜6か月。月1万円に届いた例は約3.5か月（毎日投稿、Amazonアソシエイト中心）だが、これは成功側の例。AI量産で毎日投稿しても30日で売上0円・1記事14PVという失敗例もある。月10万円以上の例は、外部SNSの大きなフォロワーや副業経験がある人に偏っている。
3. 「海外YouTubeの日本語要約」は note 上にすでに競合が多い。さらに YouTube の英→日オートダビングで「翻訳しただけ」の価値は下がっていく。収益化の軸は、要約ではなく「実験・体験（本人が書く部分）」と、無料記事からメンバーシップや有料まとめへの導線になる。手数料の手取りは約83〜85%（1回の振込ごとに別途270円）。

## リスク・規約

1. **競合と差別化**：海外の大物YouTuberの人気動画は、日本語の要約 note がすでに複数ある（書き起こしまである）。brand.yaml の採用基準「日本語で検索してもほぼ情報が出てこない」を満たす題材は限られる。加えて、YouTube の英→日オートダビングがデフォルトで有効になり、「翻訳するだけ」の価値は時間とともに下がる。
2. **著作権**：全文の書き起こしや翻訳を公開すると、ガイドラインの禁止事項（他者の著作権侵害）に当たりうる。CLAUDE.md の方針（要約＋考察、引用は最小限）を守る。
3. **AI量産とスパム判定**：note 規約に AI 明記の義務はない。ただし「スパム行為と当社が判断した場合」は削除・停止の対象。Google も、価値を加えない大量生成ページをスパムとして扱いうる。1日1本・体験部分は本人が書く、という現行ルールはこの両方への対策として妥当。
4. **売上公開による煽りの禁止**：規約に「売上…を公開して…購入を煽る」ことが停止事由として明記されている。「月○万円稼いだ」系の訴求で有料記事を売るのは避ける。
5. **Amazon**：note の Amazon カードに自分のアソシエイトIDを付けないと、note のタグが自動で入る（紹介料が自分に入らない）。アソシエイト参加の表記義務、ステマ規制の PR 表記（冒頭）、180日以内に3件という審査条件を満たす必要がある。本の紹介料は3%なので、1,700円の本1冊で約51円（推計：1,700×3%）。
6. **手数料**：キャリア決済の購入が多いと手取りは約76.5%まで下がる（1−15%、残額の10% → 0.85×0.9）。振込は1回270円なので、少額の売上はまとめて受け取る。
7. **AI学習対価還元**：規約上、記事は原則として学習データ提供の対象になる（オプトアウト可）。分配額は未定なので、収益として見込まない。
