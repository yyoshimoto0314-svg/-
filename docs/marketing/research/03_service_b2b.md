# 問い

note記事作成・動画編集を「代行サービス」として売る場合の相場・需要・競合はどうか。特に中小企業・士業向けのコンテンツ発信代行は成り立つか。

- 調査日：2026-10-02（JST）／調査担当：marketing-researcher
- 前提：本組織は「note記事の自動作成（リサーチ→執筆→校正→QA）」と「動画の自動編集（無音カット・字幕・縦型化・サムネ）」を持つ（`docs/00_roadmap.md` Step 7「サービス化」）。オーナーは士業向けコンサル会社勤務で、士業への販路を持つ可能性がある。

## 結論（3行）

1. **「記事を書くだけ」「動画を切るだけ」の単品代行は AI で価格が崩れており勝てない**（クラウドソーシングの記事は文字単価0.5〜2円、ショート動画編集はココナラで1本2,000円〜）。単品の受託で稼ぐのは厳しい。
2. **士業向けの「業法チェック込み・発信まるごと代行」は月4.8万〜14万円で既に商品として成立している**（例：Sincere Japan）。一般向けのSNS／ショート動画運用代行（月10万〜50万円）より安い価格帯が空いていて、「月5〜10万円で note 月4本＋ショート月8本＋業法・景表法チェック」は相場と矛盾しない。
3. ただし、税理士の新規顧問先は**紹介経由が中心**で（80%以上が紹介を重視）、発信の成果が出るまで3〜12か月かかる。このため**集客代行として売ると解約されやすい**。売り方は「信頼の材料（紹介された見込み客が見るプロフィール／専門性の証拠）づくり」とし、オーナーの販路で**小さく検証する（3〜5事務所の有償パイロット）**のが妥当。確信度は中。

## 成功例 / 失敗例・中央値

- **成功例**
  - Sincere Japan は、士業特化と「全投稿の業法チェック」を差別化にして、月4.8万円から商品化している。低価格帯の士業特化代行は成り立っている。
  - 税理士法人のYouTube運用支援では、約1年の伴走で登録者数千人・1本あたり数千回再生まで伸び、集客と採用に効果があったとされる（[StockSun 事例](https://stock-sun.com/example/attracting-customers/youtube-operation-for-attracting-customers-and-recruiting-tax-accounting-firms/)。**検索結果の要約で、ページは未確認**）。
- **失敗例・注意点**
  - SNS運用代行で最も多い不満は「期待した成果が出ない」。成果が数字に表れるまで3〜6か月、B2Bでは6〜12か月かかる。このため最低契約期間を6か月にする会社が多い（[S.Line 契約の注意点](https://s--line.co.jp/sns-agency-contract-tips/)。**検索結果の要約**）。
  - 「AIっぽい」コンテンツはB2Bの購買担当者の約半数を離脱させる（Forbes JAPAN、上の表）。AIで量産しただけの発信は、士業の信用を逆に損なうおそれがある。
  - 単品の受託は価格の底が非常に低い（ショート編集2,000円/本、記事1円/文字）。ここで勝負すると、時間単価が最低賃金を下回る水準の競争になる。
- **中央値**：代行会社の売上・解約率・顧客1社あたりの平均単価の中央値を示す公開データは**見つからなかった**。

## リスク・規約

1. **税理士の広告規制（日税連「会員の業務の広告に関する細則」）**：禁止は「事実に合致しない」「誤認・誤導のおそれ」「誇大・過度な期待」「過度な不安をあおる」「他の会員と比較」「品位を損なう」広告。さらに「税務行政庁での具体的役職名」「依頼者の氏名・名称」「取扱い中・過去の事案」は、依頼者の書面同意がない限り表示できない。HP・SNS・動画もすべて対象。NG例は「贈与税をゼロにします」「最安の税理士」「顧問先：A社、B社」「元○○税務署長」「契約で商品券プレゼント」（[JMSC 税理士の広告規制](https://www.jmsc.co.jp/knowhow/topics/10437.html)）。→ **AIが書く「節税できる」「〇〇万円得する」系の煽る見出しは、そのまま違反候補になる**。
2. **弁護士（日弁連「業務広告に関する規程」・指針、2025-02-20改正）**：禁止類型は税理士とほぼ同じ（規程第3条）。指針では、広告の主体は全体を見て判断し、依頼者などの談話・推薦文も含めて違反かどうかを判断するとしている。第三者が違反する表示をし、弁護士がそれに対価を払う・協力することも禁止（規程第8条）。広告は3年間の保存義務があり、Web・SNS・動画のデータと、**広告業者（代行業者）との契約書・見積書・請求書なども保存の対象**（[日弁連 業務広告に関する指針PDF](https://www.nichibenren.or.jp/library/pdf/jfba_info/rules/other/shishin_kaiki_44.pdf)、実物で確認）。→ 代行業者側も、納品物と契約記録を残せる体制が必要。
3. **ステマ規制（景品表示法、2023年10月から）**：事業者の表示であることが一般消費者に分かりにくい表示は不当表示になる。事業者が第三者を装って投稿すれば対象（[BUSINESS LAWYERS](https://www.businesslawyers.jp/articles/1310)ほか。**個別ページは未確認、検索要約**）。→ 士業本人のアカウントで発信し、なりすまし投稿や「お客様の声」の捏造はしない。代行業者自身のメディアで士業を紹介する場合は PR 表記をつける。
4. **専門内容の正確性と責任の所在**：税務の記述が誤っていると、士業の信用を損ない、懲戒の対象にもなりうる。代行業者は「税理士業務」（税務相談など）をしてはいけないので（税理士法。条文は今回未確認）、**最終的な内容の監修と公開の承認は必ず士業本人**とする。本組織の憲章（数字・法律・税務は出典を確認できたものだけ書く／公開は人間の承認後）と相性がよい。
5. **AIへの不信**：TDB 調査では、企業の懸念の1位が「情報の正確性」で50.4%。「AIで作っています」を前面に出すより、「本人の一次情報を取材し、専門家が監修している」を前面に出すべき。
6. **YouTube**：AIの利用自体は収益化停止の理由ではないが、テンプレートで量産した動画は「inauthentic content」と判定されるおそれがある。ただし士業の目的は広告収入ではなく集客なので、影響は限定的。

## 競合の多さと差別化の余地

- **競合はとても多い**：記事・動画の単品はクラウドソーシングとココナラの個人が最安値帯を埋めている。SNS運用代行は月10万〜50万円の会社が多数ある。士業特化でも Sincere Japan（月4.8万円〜）、StockSun、ビーヘルシーなどがいる。
- **空いていると考えられる場所（推計・仮説）**
  1. **価格帯の空白**：一般の運用代行は月10万円以上、士業特化の Sincere は月4.8万円で「SNS投稿12本」。**note（長文）とショート動画を組み合わせ、業法チェックまで含めて月5万〜10万円**という商品は、今回の調査では見当たらなかった。
  2. **長文1本から複数の媒体へ展開**：本組織のパイプラインは「記事→台本→字幕→ショート」が自動でつながる。1回の取材（15〜30分の録音）から note 1本とショート3〜5本を作れれば、原価を下げられる。
  3. **業法チェックをQA工程に組み込む**：`qa-reviewer` に、日税連細則・日弁連規程・景表法のチェックリストを持たせる。Sincere が差別化の柱にしている点を標準装備にする。
  4. **販路**：税理士の新規獲得は紹介が中心のため、コールドの営業は効きにくい。オーナーのコンサル会社経由の紹介は、この業界の買い方に合っている。ただし、勤務先との利益相反・副業規定の確認が先（**未確認事項**）。
- **差別化しにくい点**：「AIで安く作る」は差別化にならない（誰でもできるうえ、発信者の信用を下げる）。
