## 指摘（重要度順）

### [必須]

1. **§4「録音30分から note 1本とショート2〜4本を作ります」** — 根拠のない内容を、提供の事実として言い切っている。調査では「1回の取材（15〜30分の録音）から note 1本とショート3〜5本を**作れれば**原価を下げられる」という仮説で、本数も違う（3〜5本）。さらに文書の中でも矛盾がある。ヒアリングは月1回30分なのに、スタンダードは note 月4本（ライトでも2本）。「30分で note 1本」ならヒアリング1回では足りない。
   → 直し方：「1回のヒアリング（30分）から複数の記事と動画を作ることを目指します（**仮説**。試験契約で、1回の録音から何本作れるかを実測します）」とする。プランの本数とヒアリングの回数・長さをそろえる（例：スタンダードはヒアリング月1回60分、または月2回）。

2. **§4「やらないこと」1つ目「税務相談に答える内容を、代行側が独自に書くこと（税理士業務に当たるため）」** — 法律の書き方が不正確で、言い過ぎ。税理士法の「税理士業務」（税務代理・税務書類の作成・税務相談）の中の「税務相談」は、個別の納税者からの具体的な相談に答えることを指すと一般に解されている。不特定の読者向けの一般的な解説記事を書くこと自体が、直ちに税理士業務になるとは言えない。しかも代行調査では「条文は今回未確認」となっており、憲章の「法律は出典を確認できたものだけ書く」に反する。
   → 直し方：理由を「税務の判断や個別の相談への回答は税理士の仕事で、税理士でない者はできないため（税理士法。条文は提案前に確認）」とし、ルールを「代行側は税務の判断・解釈を書かない。税務の内容はすべて士業本人の話と監修に基づく」とする。条文（税理士法第2条・第52条とされる）を一次資料で確認してから番号を書く。確認できなければ条文番号は書かない。

3. **§8 本文「関門で条件を満たせなければ中止します。」** — 直後の文、および判断レポート §5 と矛盾している。12/31 に1件以下なら「1回だけ見直し」、10時間超なら「値上げか本数を減らす」であり、中止ではない。読み手は「12/31に2件なければ即中止」と受け取る。図2 は3つを同じ形の「関門」として並べているので、誤解が強まる。また 10/16 は**目標**で、レポートの撤退ラインは「NG、または **10/31までに**確認できない」。
   → 直し方：「関門ごとの対応は次のとおりです」とし、対応を箇条書きにする。10/16（目標。NG なら中止、10/31までに確認できなければ中止）、11/30（有償契約0件なら中止）、12/31（1件以下なら価格と内容を1回だけ見直し、次の90日でも2件未満なら中止。10時間超は値上げか本数減）。図2 の 12/31 には「判断（中止ではなく見直し）」と分かる補足を足すか、本文で明示する。

4. **§4 料金プランの本数 と §7 の「確認作業だけで約4時間」** — (a) 冒頭の「料金はすべて仮の価格」は価格だけを指しており、**本数（2本/4本、4本/8本）とプランの構成も仮**だと書かれていない。(b) 判断レポートは月4.8万〜6万円を「note 月4本＋ショート月8本」として計算している。企画書はライト（4.8万円）を「note 2本＋ショート4本」に半減させたが、その変更が書かれていない。(c) §7 の収支①②はライト4.8万円で計算しているのに、「1社の確認作業だけで約4時間」はレポートの 4本×30分＋8本×15分 の計算で、ライト（2本＋4本）なら約2時間になる。前提がずれている。
   → 直し方：§4 の冒頭を「料金・本数・プラン構成はすべて仮です」とする。§7 の4時間の文を「スタンダード（note 4本＋ショート8本）の場合、確認作業だけで約4時間かかる見込みです。ライトでは約2時間ですが、ヒアリングと監修のやり取りを足すと5時間は楽観的な値です」のように、どのプランの話かを明記する。判断レポートとの違い（レポートは4.8万円で4本＋8本）を脚注で1行書く。

5. **§3 表「月に1回30分のヒアリングだけで、記事と動画を作る」** — 顧客（士業）の負担を少なく見せている。企画書自身が「士業本人の監修・承認」を必須としており（§4、§5、図1の差し戻しループ）、30分では済まない。提携先や顧客に見せると、約束と違うという不満や解約につながる。
   → 直し方：「月1回30分のヒアリングと、できあがった原稿・動画の確認（目安◯分）で発信できる」とする。確認時間の目安は試験契約で測る旨を添える。

### [推奨]

1. **§1「なぜ今」「まだ月5万〜10万円の価格帯に競合が少ない」** — Sincere（4.8万/8.5万円）はまさにこの価格帯にいる。調査が言っているのは「note＋ショート＋業法チェックの組み合わせを月5〜10万円で出す商品が見当たらなかった」こと。→ §2 の結びと同じ言い方にそろえる。また自社のライト（4.8万円）は「月5万〜10万円」の外にあるので、§1・§6 の価格帯は「月4.8万〜6万円」で統一すると誤解がない。
2. **§2「このうち数十事務所と契約できれば事業として成り立ちます」** — 根拠のない主張。§7 では10事務所でも外注が前提で、収益は2社で計算している。→ 削除するか、「10事務所で月60万円の規模になります（推計）」程度にする。
3. **§3「紹介された人は、会う前に事務所の名前で検索します」／表「note と動画が、検索結果に並ぶ」** — 調査では仮説（売り方の考え方）で、データはない。検索順位も保証できない（調査では、note は士業の集客経路として実証されていない）。→ 「検索することが多いと考えられます（仮説）」「並ぶことを目指す」に弱める。
4. **§4 最低契約6か月と試験契約3か月** — 同じ節にあって矛盾して見える。→ 「最低契約期間6か月は本契約（ライト・スタンダード）に適用。試験契約は3か月限定」と明記する。
5. **§7 将来像（10事務所・月60万円）** — 判断レポートは「根拠がないので楽観にも入れない」としている数字。→ 「楽観シナリオ（5事務所×6万円＝月30万円）より上の目安で、根拠はない」と添える。5社以上では AI 利用料が月30,000円に上がる前提（判断レポート §2）も1行足す。
6. **§7 表の列名** — 「作業時間/月」に営業10時間が含まれ、「手残り」で AI 利用料も引いていることが表から分からない。→ 「作業時間/月（営業10時間を含む）」「手残り/月（AI利用料と作業時間の時給換算を引いた後）」とする。
7. **§2 表「記事の月額パッケージ 月5万〜10万円で2〜4本」** — 根拠は「執筆のみ」。→ 「（執筆のみ）」を足す。
8. **§1「税理士などの士業」と §9「最初は税理士に絞る」** — 対象の範囲がずれている。チェックリストは税理士・弁護士・景表法だけで、社労士・司法書士・行政書士の業法は入っていない（Sincere は4業法）。→ §1 に「最初は税理士事務所に限る」と書く。
9. **§3「コンテンツを『AIで作られた』と感じると」** — 調査は「**営業**コンテンツ」について、「問い合わせや資料請求をやめる」と答えたもの。→ 「営業コンテンツを…」とする。
10. **§9 リスク表のリンク「日税連の広告細則」** — リンク先は日税連ではなく JMSC の解説記事。→ 「日税連の広告細則（JMSC の解説）」とする。ステマ規制の行は根拠が検索要約だけなので、出典を1件確認して載せる（消費者庁のページなど）。
11. **図1「AIが制作」と §5 本文「AIが担うのは下書きと編集だけ」** — 言い方が違い、図だけを見るとAIが完成品を作るように読める。→ 図の見出しを「AIが下書き・編集」にそろえる。「規制チェック」を誰がするか（AIのチェック＋担当者の確認か）も一言あるとよい。
12. **§9 弁護士の行「代行業者との契約書・請求書も3年間の保存対象」** — 保存義務があるのは弁護士側。→ 「弁護士には広告の3年間保存義務があり、代行業者との契約書・請求書も対象」とする。
13. **社外に見せる場合の内容（§5・§7・§9・§10）** — 「このリポジトリの既存の仕組み」、リポジトリ内のパス（`docs/marketing/...`）、オーナーの時給換算、「勤務先の副業規定・利益相反」は社内向けの情報。提携先や勤務先にそのまま見せると、意味が通じないか、オーナー個人の事情をさらすことになる。→ 社外向けの版を作るときは、§7 の時給換算・§9 の1行目・§10 と内部パスを外す（下の「人間の確認」1）。
